# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 中控与现场工作内容各自独立：中控只持有议程、发言人、术语表和紧急通知（工作副本），现场只持有传译队列、术语提醒与上屏内容。
- 中控修改不会实时影响现场：改完点「下发新版本」封版，按议程/术语/通知逐条下发，现场集齐整版并完成回执后才切换；没收到前照旧版继续。
- 上屏段落冻结当时那版译法（每条队列带术语版本号与标签快照），新版本只重新解释未确认的条目，已确认内容永不回改。
- 发件箱按条目记账、逐条回执；下发到一半断网时现场照常干活，恢复后按回执对账，只补发没同步上的条目，已确认的内容不在发件箱中、不会重发。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认（提醒走现场侧，不依赖中控在线）。
- 紧急通知先保存中控，标记发布并随版本下发、现场收版后才进入上屏区。
- 网络中断时继续手工录入本机暂存；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化（中控/现场分别存储）、撤销重做（按工作区区分）与字号偏好恢复。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示。中控工作副本与发件箱（`conference-control-v1`）、现场队列、已收版本快照与同步日志（`conference-live-v1`）分别保存在当前浏览器；「下发对账」页可模拟断网/恢复并观察逐条补发过程。清理站点数据会移除本地记录。
