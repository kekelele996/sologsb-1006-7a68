# 会议同传提示台

面向会议管理员（中控）和同传人员（现场）的提示台。**中控与现场各自持有独立的工作内容**：中控管议程与术语表，现场管队列与上屏。中控改完术语表下发新版本，现场收到完整版本后才切换；已确认上屏的段落保留当时那版译法，新版本只作用于未确认条目。下发中断网时现场照常干活，恢复后按回执对账、只补未同步条目。

## 数据主权分离

- **中控（`controlStore`）**：发言人、演讲顺序（议程）、术语表草稿。编辑不会影响现场；点击“下发新版本”后生成一个带版本号的术语表快照，逐条下发。
- **现场（`siteStore`）**：传译队列、舞台上屏、术语提醒、紧急通知、离线暂存。现场只在**收到完整版本**后才切换术语表版本；没收到（含只收到一部分）就照旧版继续。
- **网络（`netStore`）**：共享在线/离线状态。现场恢复在线时合并离线暂存；中控恢复在线时自动按回执对账补下发。

## 版本下发与回执对账

- 每个版本包含若干**条目**（术语），逐条下发，现场收到一条即记一条**回执**。
- 全部条目送达后，版本进入现场的“待切换”缓冲；现场可选择**切换**或**稍后**。
- 切换时：**未确认**条目按新术语表重算译法标签；**已确认上屏**条目冻结，保留当时版本的译法（标签与版本号都不变）。
- 下发到一半断网：已送达条目保留回执，未送达条目挂起，现场不切换、照旧版干活。
- 恢复网络后**按回执对账**：只补下发没有回执（没同步上）的条目，已回执（现场已确认收到）的内容不重复下发。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知（中控）。
- 自动接入现场文字并进入传译队列；可手动模拟下一段。
- 逐条确认已传上屏、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认；现场只显示当前已应用版本的术语。
- 紧急通知先存草稿，发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后自动合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化（中控、现场各自独立存储）与字号偏好恢复。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`（中控与现场分键存储）

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，用逐条定时下发模拟“中控 → 现场”的版本同步，用顶部网络按钮模拟断网与恢复。所有数据保存在当前浏览器，清理站点数据会移除本地记录。
